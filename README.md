Upload these files to the root of a public GitHub repository, then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**.

Store links:
- Privacy Policy: `privacy.html`
- Terms: `terms.html`
- Community Guidelines: `community.html`

Before launch, have the legal text reviewed by a qualified lawyer, particularly before adding payments, precise geolocation, identity verification or subscriptions.
